Dates understand ISO (2026-09-10), M/D, "next <day>", "in N days/weeks", month names, "today/tomorrow/yesterday", and "eod". A date with no clock time becomes a deadline; a clock time (with or without a date) becomes a timed calendar event — both show up on the Schedule calendar. Add !high, !medium, or !low anywhere to set a deadline's priority.
Need something that repeats — a weekly meeting, a monthly bill reminder? Open Schedule and use + Add Event for full control over recurrence, specific weekdays, and an end date/count.
Classes vs Events vs Deadlines, in one line: Classes are your fixed weekly course schedule (set once, edited from the Classes list); Events are anything else with a time or a repeat pattern — meetings, appointments, recurring bills, workouts — added from Schedule → + Add Event; Deadlines are things due by a date with no time slot, like assignments — add those from Quick Capture or the Deadlines list. When in doubt: has a specific time or repeats on a schedule → Event. Just due by a date → Deadline.

🔒 Sync this dashboard across devices

Optional. Enter a passphrase and a GitHub personal access token (scoped only to "gist") to sync all your data — classes, budget, to-dos, everything — to a private encrypted GitHub Gist. Same passphrase + token on another device loads the same data.

Use a different token
Don't have a token yet? Go to github.com/settings/tokens → Generate new token (classic) → check only the "gist" box → generate, then paste it above. Your passphrase never leaves this browser — only encrypted data is sent to GitHub.
